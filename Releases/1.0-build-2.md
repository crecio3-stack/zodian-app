# Zodian 1.0 (Build 2)

Date: 2026-04-13

## Build Intent

Stabilization and ship-readiness pass focused on onboarding, Home reveal behavior, Connect polish, metadata prep, and release hygiene.

## What Changed

- Cleaned up remaining iOS 17 `onChange` deprecation call sites

- Expanded Connect card layout so Essence, Connection Energy, and Why This Match show more readable copy
- Replaced the repeated six-image Connect portrait loop with larger Pexels portrait pools
- Matched masculine/feminine-coded profile names to the corresponding portrait pools
- Standardized current icon/logo asset filenames in the asset catalog
- Added repo-tracked App Store metadata and release-notes scaffolding

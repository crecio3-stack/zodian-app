# Shadow Story Pipeline v1 — Review

All entries are internal briefs, not reader-facing prose. Each holds a temporary, identity-linked tension open rather than supplying the writer’s lesson or the reader’s action.

## libra-snake-boundary

- Identity/signal: Libra × Snake; `commonBlindSpots` — Charm can obscure when a firmer boundary is needed.
- Pressure: A small discomfort keeps getting softened so the real limit stays unnamed.
- Brief: daily thread — A softened discomfort is asking for a clear limit. Central tension — Keeping the mood easy versus naming what no longer works. Question — What changes once the issue is named without managing every reaction? Hook — The problem is not as small as it has been made to seem. Shift — The silence has started to change the balance on its own. Landing — What stays unnamed is already shaping the connection.
- Fit/difference: the story is about socially managing discomfort until silence changes the balance; the second Libra × Snake story is about help replacing another person’s part.

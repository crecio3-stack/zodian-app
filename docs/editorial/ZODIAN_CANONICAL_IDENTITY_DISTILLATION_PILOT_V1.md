# Zodian Canonical Identity Distillation Pilot v1

## Purpose

This four-profile pilot evaluates whether approved canonical identity material can become concise, distinct, provenance-backed editorial profiles. It proposes records for Libra × Snake, Taurus × Horse, Sagittarius × Monkey, and Gemini × Dragon. It is not wider approval or production use.

## Distillation standard

Profiles describe enduring tendencies, never daily behavior. `coreMotivations` records what drives choices; `recurringStrengths` reliable capacities; `recurringFriction` repeated inner push-pull; `commonBlindSpots` useful perspectives that can go unseen; `interpersonalPatterns` repeated behavior with people; and `emotionalPatterns` recurring internal movement.

Every profile contains all six categories. Each category contains one to four strongly supported notes; a precise single note is preferable to a second inferred or generic note.

## Distinctiveness

The four profiles must not be interchangeable. Broadly flattering or universal notes are excluded unless an approved source supports a specific identity-distinct pattern. Passing the deterministic audit does not prove editorial distinctiveness; human review remains required.

## Provenance

Every profile retains only `source:suzanne-white:new-astrology-21st-century`. It stores no file paths, pages, passages, excerpts, or source text. The profiles are proposed canonical editorial records pending review.

## Source-use boundary

Notes are concise, neutral, independently phrased internal editorial language. They do not contain astrology mechanics, zodiac symbolism, predictions, fixed scenes, source prose, or reader-facing copy.

## v1 boundary

The pilot does not choose a daily thread, generate Story Engine briefs or horoscope copy, populate identities beyond these four, connect to a provider or database, or wire into any existing layer, writer, routing, scheduler, production system, or cron job 26.

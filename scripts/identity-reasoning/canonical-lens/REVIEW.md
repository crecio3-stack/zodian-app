# Matched Comparison Review

## Result

All 20 controlled outputs pass the parity validator on their first attempt. All
10 matched pairs differ in selected context, reasoning recognition, resolution,
and final copy.

Libra × Snake repeatedly uses evidence quality, missing context, honest
exchange, and the point at which another perspective stops changing the answer.
Taurus × Horse uses accumulated constraint, practical continuity, voluntary
commitment, and the smallest adjustment that prevents later escape. The shared
tensions do not collapse into interchangeable advice.

## Quality audit

- **Identity specificity:** The matched Lenses are not safely swappable. For
  example, work/voice resolves through an earned conclusion for Libra × Snake
  and an early practical correction for Taurus × Horse.
- **Daily relevance:** Every Lens uses one visible daily arena and preserves
  open-ended horoscope language rather than retelling the full identity.
- **Recognition depth:** Each pair changes a believable starting assumption:
  more context is not always more accuracy; preserving the arrangement is not
  always the least disruptive choice.
- **Arena variety:** The ten scenarios cover work, romance, home, friends,
  money, rest, confidence, routine, conflict, and opportunity exactly once per
  identity.
- **Canonical overuse:** Some recurrence is appropriate, but Libra × Snake still
  leans heavily on evidence/conclusion and Taurus × Horse on adjustment/freedom.
  A production experiment needs rolling selection memory before broader use.
- **Personality leakage:** The focused selector prevents model dumps. A few
  deeper reads approach durable identity language, but each remains attached to
  the day's concrete situation.
- **Distinct resolution:** Libra × Snake typically resolves by deciding what the
  evidence now supports. Taurus × Horse resolves by changing one workable part
  before accumulated strain demands a larger departure.
- **Writing quality:** The copy remains plainspoken and concrete, with the same
  six-field progression and production field limits.

## Recommendation

The canonical adapter improves identity specificity enough to justify a second,
still-development-only experiment using live model writing and an extracted
shared production validator. It does not yet justify production integration.
Before that decision, add per-identity selection memory, run at least a 30-day
sample per fixture, measure theme concentration, and compare against the current
production generator blind.
